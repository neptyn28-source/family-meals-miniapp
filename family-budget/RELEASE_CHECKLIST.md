# Family Money — проверка перед релизом

## Обязательные проверки

- [ ] Муж и жена видят **все** конверты, личные расходы и комментарии.
- [ ] Посторонний без семейного токена не получает бюджет.
- [ ] Создание семьи и вход второго участника по коду.
- [ ] Расход 1250,50 ₽ уменьшает правильный конверт на 125050 копеек.
- [ ] Отрицательная сумма, ноль, NaN, дробные копейки и неизвестный конверт отклоняются сервером.
- [ ] Перевод 500 ₽ между конвертами не меняет общий остаток.
- [ ] Аванс, зарплата и премия распределяются по шаблонам.
- [ ] История содержит комментарии и суммы для обоих супругов.
- [ ] Аналитика учитывает расходы текущего месяца; неполная история явно обозначена.
- [ ] Оба телефона получают обновления после перезагрузки.
- [ ] Существующие данные семей сохранены после обновления API.
- [ ] Проверка мобильного Telegram WebView и Safari/Chrome.
- [ ] Бэкенд обновлён и протестирован **до** слияния PR в main.

## Блокеры

Текущий сервер ограничивает операции с чужими личными конвертами. Интерфейс уже открыт обоим супругам, но API пока не приведён к этой модели. Не выпускать в production до исправления и проверки серверной валидации.

Текущая аналитика построена по последним 80 операциям; для точного месячного отчёта нужна серверная агрегация или пагинация.
